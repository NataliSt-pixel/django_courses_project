# Django Courses Project

Проект Django для управления курсами и студентами с полным покрытием тестами.

## Функциональность

- REST API для курсов и студентов
- Фильтрация курсов по ID и названию
- Полное CRUD для курсов
- Ограничение количества студентов на курсе

## Тестирование

Проект включает comprehensive тестирование:

- Тесты получения курсов (retrieve/list)
- Тесты фильтрации
- Тесты создания/обновления/удаления
- Фикстуры с model_bakery

## Запуск

```bash
# Установка зависимостей
pip install -r requirements-dev.txt

# Миграции
python manage.py migrate

# Запуск тестов
pytest
